# Червоне · Чорне 🔴⚫

Проста гра-казино для iPhone: один стіл, великий екран результату і дві кнопки — ЧЕРВОНЕ та ЧОРНЕ. Стіл живе у ритмі казино (15 секунд ставки, 15 секунд крутиться), але щойно тапнув колір — результат показується ОДРАЗУ, чекати не треба. Не ставиш — воно собі крутиться.

## Правила
- **Чотири кнопки, без перемикання**: великі 💰 ЧЕРВОНЕ/ЧОРНЕ — реальна ставка грошима; сірі пунктирні ЧЕРВОНЕ/ЧОРНЕ (ФЕЙК) — просто вгадування без грошей.
- **Реальна ставка**: гроші по драбині як у казино — програв, наступна ставка більша (10 → 20 → 40 → 80 → 160…, рахується з банку, кратність 5, все «до останнього»). Вгадав — сума додається і драбина спочатку. Програв усі кроки — серія згоріла.
- **×2 СТАВКА**: тапни її перед реальною ставкою — поставиш цей і наступний крок драбини одночасно (два ходи за один). Вгадав — забрав обидва; мимо — драбина стрибає одразу через два кроки. На останньому кроці недоступна.
- **Пропустити ▸▸** — прокрутити спін без ставки, число покажуть, нічого не рахується.
- **Коли крутиться — ставки закриті**: смуга стає повністю червоною з написом «Ставки закрито», без відліку. Тапнеш кнопку — гра просто скаже «Ставки закрито», і все. Відкриється — ставиш.
- **Результат без слів**: зелена ✓ — вгадав, червоний ✗ — ні. Цифра в історії з'являється тільки РАЗОМ з великим результатом, не раніше.
- **Мітки: 100% · ++ · + · ? · ?? · M · MM · єЦіль** — тапни перед ставкою, і в статистиці буде розбивка: скільки вгадав з кожною міткою і який відсоток. Ставки без мітки теж рахуються окремим рядком.
- **Статистика «з якого разу вгадував»** — по кроках драбини (з 1-го, з 2-го…), рахуються ТІЛЬКИ реальні ставки.
- Кнопка **↺** вгорі (два тапи) скидає рахунок/кроки до дефолту; свій дефолт зберігається в ⚙ кнопкою «Зберегти поточне як дефолт».
- Біля балансу — **сумарний виграш/програш і відсоток від початкової суми** (зелений плюс або червоний мінус). Точка відліку — сума, з якої почав (скидається кнопкою ↺ або новим рахунком у ⚙). Баланс оновлюється тільки РАЗОМ з цифрою, що випала — без спойлерів під час крутіння.

## Файли
- `index.html` — уся гра (HTML + CSS + JS в одному файлі)
- `manifest.json` — щоб виглядала як застосунок
- `sw.js` — щоб працювала офлайн
- `icon-512.png` — іконка
- `README.md` — ця інструкція

## Як викласти на GitHub Pages
1. Зайди на github.com під своїм акаунтом
2. New repository → назва `my-game-3` → Public → Create
3. Перетягни файли з цієї папки у вікно браузера → Commit changes
4. Settings → Pages → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save
5. Через 1–2 хвилини гра буде за адресою: `https://ТВІЙНІК.github.io/my-game-3/`

## На iPhone
1. Відкрий посилання **в Safari**
2. Кнопка «Поділитися» (квадратик зі стрілкою внизу)
3. «На екран "Дім"» → Додати
4. Запускай з іконки — на весь екран, працює без інтернету

## Оновив гру?
